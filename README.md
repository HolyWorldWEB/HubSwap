# HubSwap

**Автоматический переход между серверами (Lite / Classic / Prime / Lite 1.20) на проекте HolyWorld.**

Мод позволяет мгновенно переключаться между серверами через команды, хоткеи и кликабельные ссылки в чате. Полностью настраиваемый, с поддержкой алиасов, диапазонов серверов и статистики переходов.

---

## 🔧 Возможности

- **4 режима:** Lite (1–74), Classic (1–3), Prime (1–9), Lite 1.20 (1–3).
- **Команды:** основные (`/ln`, `/cn`, `/pm`, `/ln120`) и **настраиваемые алиасы** (например, `/an`, `/ан`, `/ft`).
- **Подкоманды:** `top` и `down` для навигации по серверам (например, `/an top 3`).
- **Хоткеи:** до 8 клавиш с привязкой к режиму и номеру сервера.
- **Ссылки в чате:** кликабельные названия серверов (например, «Лайт #12» или «Classic #2»).
- **Автосохранение статистики:** каждые 30 секунд, данные не теряются при краше.
- **Настройка диапазонов:** для Lite можно изменять количество серверов в категориях Solo/Duo/Trio/Clan.
- **Цветовые темы и уведомления:** настраиваемый интерфейс.

---

## 📦 Установка

1. Скачайте последний релиз из [Releases](https://github.com/Heldyy90/HubSwap/releases).
2. Поместите `.jar` файл в папку `mods` вашего клиента Fabric (версия 1.20.1).
3. Запустите игру.

---

## ⌨️ Команды

### Основные (жёсткие)
| Команда          | Действие                         |
|------------------|----------------------------------|
| `/ln <номер>`    | Переход на Lite #номер           |
| `/ln120 <номер>` | Переход на Lite 1.20 #номер      |
| `/cn <номер>`    | Переход на Classic #номер        |
| `/pm <номер>`    | Переход на Prime #номер          |

### Алиасы (настраиваемые)
Вы можете добавить свои алиасы через GUI (вкладка «Режимы»). Например:
- `an`, `ан`, `ft` → Lite (по умолчанию)
- `cl` → Classic
- `pr` → Prime

**Для любого алиаса работают подкоманды:**
- `/алиас top [шаг]` → переход на N серверов вверх (в текущем режиме)
- `/алиас down [шаг]` → переход на N серверов вниз

*Пример:* `/an top 3` → переключиться на 3 сервера вверх в режиме Lite.

---

## 🎮 Хоткеи

В настройках (вкладка «Хоткеи») можно привязать до 8 клавиш к конкретному переходу:
- Выберите клавишу (нажмите на кнопку и нажмите клавишу).
- Выберите режим (Lite / Classic / Prime / Lite 1.20).
- Укажите номер сервера.
- Включите хоткей.

При нажатии клавиши мод автоматически выполнит переход.

---

## 🔗 Ссылки в чате

Мод автоматически преобразует названия серверов в кликабельные ссылки.  
Поддерживаются варианты:
- **Lite:** `Лайт #12`, `lite 12`, `Лайт12` (регистр не важен)
- **Classic:** `Классик #3`, `Classic 3`, `Clasik#2`
- **Prime:** `Прайм #7`, `Prime7`
- **Lite 1.20:** `лайт 1.20 #2`, `lite120 1`

При нажатии на ссылку выполняется соответствующая команда перехода.

## ⚙️ Настройки

Откройте GUI настройки клавишей `F4` (по умолчанию) или через меню.

### Вкладки:
- **Основные:** таймаут, уведомления, цветовая тема, цвет ссылок.
- **Режимы:** настройка алиасов для каждого режима.
- **Диапазоны:** настройка количества серверов и категорий Lite (Solo/Duo/Trio/Clan).
- **Хоткеи:** привязка клавиш.
- **Статистика:** общее число переходов, любимые серверы, время на серверах.

---

## 🛠️ Настройка диапазонов

Для режима **Lite** вы можете изменить количество серверов в каждой категории (Solo, Duo, Trio, Clan) и общее количество серверов.

1. Откройте настройки (`F4`).
2. Перейдите во вкладку **«Диапазоны»**.
3. В блоке **Lite**:
   - Поле **«Lite всего»** – общее количество серверов.
   - Для каждой категории (**Solo**, **Duo**, **Trio**, **Clan**) есть поля **Min** и **Max** – начало и конец диапазона.
4. Измените значения в полях, затем нажмите **«Сохранить»**.
5. Изменения применяются сразу (перезапуск не требуется).

*Пример:* если вы хотите, чтобы Solo охватывал серверы с 1 по 20, а Duo с 21 по 40, просто измените соответствующие числа.

## 📂 Файлы конфигурации

- `config/hubswap.json` – основные настройки (алиасы, диапазоны, хоткеи, темы).
- `config/hubswap_stats.json` – статистика переходов (автосохраняется).

При первом запуске мод мигрирует настройки из старых файлов AnarchyHollyWorld (если они есть).
